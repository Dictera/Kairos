## Security Threat Model (ASVS L1)

### Applicable ASVS Categories
- ASVS 14.2 — Dependency: Third-party components (shadcn/ui, Lucide) from official registry only
- ASVS 4.1 — General Access Control: Placeholder pages must still be behind middleware auth guard

### Threats & Mitigations

| Threat | STRIDE | Mitigation |
|--------|--------|------------|
| Placeholder page accidentally rendered without auth (middleware bypass) | Elevation of Privilege | Middleware from Plan 01-04 covers all routes globally; placeholder pages have no special auth exemption needed |
| shadcn component installed from untrusted third-party registry | Tampering | UI-SPEC.md §Registry Safety: only shadcn official registry used; no third-party registry components in Phase 1 |
| `lib/db.ts` or server-only code imported into `components/providers.tsx` (client component) | Information Disclosure | `components/providers.tsx` only imports from `@trpc/tanstack-react-query`, `@tanstack/react-query`, and `@trpc/client` — never from `lib/db.ts` or `lib/trpc/init.ts` |
| `TRPCProvider` configured with incorrect URL, potentially leaking requests to external host | Information Disclosure | `httpBatchLink` url is hardcoded to `/api/trpc` (relative URL) — no external host possible |
</threat_model>

**Step 2 — Create `components/providers.tsx`** (client component — TRPCProvider + QueryClientProvider):
```tsx
'use client'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { createTRPCClient, httpBatchLink } from '@trpc/client'
import { TRPCProvider } from '@trpc/tanstack-react-query'
import superjson from 'superjson'
import type { AppRouter } from '@/lib/trpc/routers/_app'
import { useState } from 'react'

export function Providers({ children }: { children: React.ReactNode }) {
  const [queryClient] = useState(() => new QueryClient())
  const [trpcClient] = useState(() =>
    createTRPCClient<AppRouter>({
      links: [
        httpBatchLink({
          url: '/api/trpc',
          transformer: superjson,
        }),
      ],
    })
  )
  return (
    <QueryClientProvider client={queryClient}>
      <TRPCProvider trpcClient={trpcClient} queryClient={queryClient}>
        {children}
      </TRPCProvider>
    </QueryClientProvider>
  )
}
```
