## Interaction Patterns

### Template Editor (Tiptap)
- Toolbar: bold, italic, underline, bullet list, numbered list, headings (H1/H2), horizontal rule
- Variable insertion: dropdown menu in toolbar listing all 15 predefined variables (D-04) + custom variables
- Click variable in dropdown → inserts `{{variable_name}}` at cursor position
- Placeholder text when editor is empty: `Dilekçe içeriğini girin...`

### Petition Generation Flow
1. User selects template from dropdown (filtered by category tabs)
2. Variables auto-fill from case data — displayed as read-only chips
3. User can override any variable value via input fields
4. "Önizle" button shows PDF preview in modal (scrollable)
5. Two actions: "Kaydet" (saves to case Belgeler) or "İndir" (direct download)
6. Sonner toast confirms save success

### Reports Dashboard
- Three tabs: Portföy Raporu / Finansal Rapor / Dosya Listesi
- Each tab shows: summary stats cards + charts + data table
- Export buttons per section: PDF (pdfmake) and/or Excel (exceljs)
- Filter controls: date range selector (ay/yıl)
