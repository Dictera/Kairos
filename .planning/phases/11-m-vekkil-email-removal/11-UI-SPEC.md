## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #F5F0E8 (warm beige) | Background, surfaces |
| Secondary (30%) | #032539 (navy) | Sidebar, primary text foreground |
| Accent (10%) | #FA991C (orange) | Primary buttons, focus rings, CTAs |
| Destructive | oklch(0.577 0.245 27.325) | Delete actions, error banners, linked-dosya warnings |

Accent reserved for: primary CTA buttons ("Kaydet", "Yeni Müvekkil Ekle"), focus ring highlights, sidebar active state, toast success icons. Never used for body text or secondary actions.

Existing color application in muvekkil pages:
- `bg-primary text-primary-foreground` — primary buttons (orange)
- `text-destructive` — form validation errors, delete menu items
- `bg-destructive/10 border-destructive/30 text-destructive` — error banners
- `text-muted-foreground` — secondary labels and empty values (—)
- `bg-muted text-muted-foreground` — neutral badges
- `bg-green-100 text-green-800` — active status badge
- `bg-blue-100 text-blue-800` — STK type badge
