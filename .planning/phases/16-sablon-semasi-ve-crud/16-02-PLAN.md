<objective>
Implement the Python `handle_extract_vars` function in the existing docx-pipeline sidecar to extract Jinja2 placeholders (`{{ var }}` and `{%p var %}`) from uploaded `.docx` files. The Phase 15 sidecar already routes the `extract-vars` command to a stub that returns "Not implemented in Phase 15" — this plan replaces the stub with a real implementation.

**Why the Python sidecar (not docxtemplater in Node):** Phase 15 already shipped a docxtpl-based Python sidecar with execa IPC, structured logging, and exit-code contract. Reusing that sidecar for variable extraction keeps a SINGLE parsing stack (python-docx + zipfile/regex) — the same library that will eventually render the templates. Adding docxtemplater (Node) for extraction would create two divergent parsers, double maintenance burden, and risk subtle disagreement between extraction-time variable detection and render-time placeholder resolution. The sidecar IPC roundtrip cost is ~100–300 ms which is acceptable for an upload-time operation.

Purpose: Provide the variable extraction backend that the tRPC router (Plan 04) will call during template upload. Per D-02, extraction is synchronous; per D-05, only variable names are stored. The shared test fixtures (clean + fragmented) live in `tests/fixtures/` and are produced by Plan 01 (Wave 1) — this plan only consumes them.

Output: Working sidecar handler + integration test exercising both clean and fragmented fixtures.
</objective>

       The text-strip + regex approach is the explicit mitigation for RESEARCH Pitfall #1: when Word fragments `{{ muvekkil_ad }}` across multiple `<w:t>` nodes, stripping all XML tags first (`<[^>]+>` → space) collapses the fragments back into a single text stream that the regex can match.       
       ```python
       def handle_extract_vars(params: dict[str, Any]) -> dict[str, Any]:
           """Extract {{var}} and {%p var%} placeholders from a .docx file."""
           file_path = params.get("file_path")
           if not file_path:
               return {"status": "error", "code": 1, "message": "file_path param gerekli"}

           try:
               with open(file_path, "rb") as f:
                   zip_data = f.read()
           except FileNotFoundError:
               logger.error("extract-vars-missing-file", file_path=file_path)
               return {"status": "error", "code": 2, "message": f"Dosya bulunamadi: {file_path}"}
           except OSError as e:
               logger.error("extract-vars-io-error", file_path=file_path, error=str(e))
               return {"status": "error", "code": 2, "message": f"Dosya okunamadi: {e}"}

           try:
               with zipfile.ZipFile(io.BytesIO(zip_data)) as zf:
                   if "word/document.xml" not in zf.namelist():
                       return {"status": "error", "code": 1, "message": "Geçersiz .docx dosyası"}
                   xml_content = zf.read("word/document.xml").decode("utf-8")
           except zipfile.BadZipFile:
               return {"status": "error", "code": 1, "message": "Geçersiz .docx dosyası"}

           try:
               # Strip XML tags + entities to recover text where placeholders live.
               # CRITICAL: this collapses Word's fragmented {{ var }} across multiple <w:t> nodes
               # back into a single matchable text stream. See RESEARCH.md Common Pitfalls #1.
               text_content = re.sub(r"<[^>]+>", " ", xml_content)
               text_content = re.sub(r"&\w+;", " ", text_content)
               text_content = re.sub(r"\s+", " ", text_content)

               double_brace = re.findall(r"\{\{\s*([^}]+?)\s*\}\}", text_content)
               paragraph_tags = re.findall(r"\{%p\s+([^%]+?)%\}", text_content)

               combined = [v.strip() for v in (double_brace + paragraph_tags) if v.strip()]
               # Dedupe preserving first-seen order.
               variables = list(dict.fromkeys(combined))

               logger.info("extract-vars-success", file_path=file_path, var_count=len(variables))
               return {"status": "success", "result": {"variables": variables}}
           except Exception as e:
               logger.error("extract-vars-error", file_path=file_path, error=str(e))
               return {"status": "error", "code": 2, "message": f"Değişken çıkarma hatası: {e}"}
       ```
