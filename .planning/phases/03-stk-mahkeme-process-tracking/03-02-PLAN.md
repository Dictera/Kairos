- Future stages: `border border-border bg-background text-muted-foreground`. Show stage index number.
- Stage label: `text-sm flex-1`. Current: `font-semibold text-foreground`. Completed: `text-foreground`. Future: `text-muted-foreground`.

- When current is the final stage AND all stages are completed (currentIdx === stages.length - 1): show "Süreç Tamamlandı" text below the final stage in `text-sm text-muted-foreground` per copywriting contract.
- When current is null (no stage started yet): all stages show as future (empty circles). Show "Ileri Al" on first stage position to start the process.

**STK Ileri Al mutation:**
```typescript
const stkIleriAlMutation = useMutation(
  trpc.surec.stkIleriAl.mutationOptions({
    onSuccess: (data) => {
      queryClient.invalidateQueries({ queryKey: [['dosya', 'getById']] })
      const label = STK_ASAMA_LABELS[data.asama as keyof typeof STK_ASAMA_LABELS] ?? data.asama
      toast.success(`Aşama güncellendi: ${label}`)
    },
    onError: () => toast.error('Aşama güncellenirken hata oluştu. Sayfayı yenileyip tekrar deneyin.'),
  })
)
```

const initMahkemeMutation = useMutation(

      toast.success('Mahkeme süreci başlatıldı.')
