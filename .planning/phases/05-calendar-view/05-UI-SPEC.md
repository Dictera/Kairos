## Interaction Contracts

### Calendar Grid Behavior
- **Month display:** Monthly grid, Monday-week-start (`startWeekOn={1}`)
- **Navigation:** Prev/Next month buttons + `captionLayout="dropdown"` for direct month jump (D-02)
- **Today marker:** Current day highlighted via existing `today` modifier class
- **Day click with events:** Opens Popover with event list (D-03)
- **Day click without events:** Silent ignore — no popover, no state change (D-05)

### Event Badge Display (D-01)
- **Format:** "X süre, Y duruşma" inline below day number
- **Position:** Below day number, centered in cell
- **Font size:** `text-[9px]`
- **Color:** `text-red-500` for süre, `text-blue-500` for duruşma
- **Ordering:** Süre first, duruşma second (D-04)

### Event Popover (D-03, D-04)
- **Header:** Date in `dd.MM.yyyy` format (Turkish locale) + event count
- **Content:** Sorted list — süre first, then duruşma, chronological within type
- **Each item:** Type badge + event name + müvekkil adı + dosya no + (saat if duruşma)
- **Item link:** Entire item is clickable → navigates to `/dosyalar/${dosya_id}`
- **Overflow:** Scrollable internally if many events

### Data Fetching (D-06)
- **Trigger:** `month` state change via `onMonthChange`
- **Query:** Fetch only visible month (`startOfMonth` → `endOfMonth`)
- **React Query key:** `['calendar', 'monthEvents', year, month]`
- **Prefetching:** Not required — stick to D-06, use `keepPreviousData` for smooth transitions

### Turkish Locale (D-08)
- **Locale:** `date-fns/locale/tr`
- **Date format:** `dd.MM.yyyy`
- **Week start:** Monday (`startWeekOn={1}`)
- **Month dropdown:** Short month names from locale
