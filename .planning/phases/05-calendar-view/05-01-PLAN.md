From lib/trpc/routers/dashboard.ts (pattern for date range queries):
```typescript
db.select({
  id: sure.id,
  ad: sure.ad,
  son_tarih: sure.son_tarih,
  tur: sure.tur,
  dosya_id: sure.dosya_id,
  dosya_no: dosya.dosya_no,
  muvekkil_ad: sql<string>`${muvekkil.ad} || ' ' || ${muvekkil.soyad}`,
})
.from(sure)
.innerJoin(dosya, eq(sure.dosya_id, dosya.id))
.innerJoin(muvekkil, eq(dosya.muvekkil_id, muvekkil.id))
.where(and(gte(sure.son_tarih, startDate), lte(sure.son_tarih, endDate)))
.orderBy(sure.son_tarih)
```

   - eq, and, gte, lte from drizzle-orm

2. **Type definitions:**
   ```typescript
   type MonthEvent = {
     id: number
     type: 'süre' | 'duruşma'
     ad: string
     dosya_id: number
     dosya_no: string
     muvekkil_ad: string
     tarih: string  // YYYY-MM-DD
     saat: string | null  // HH:mm or null for süre
   }
   ```

3. **getMonthEvents procedure:**
   - Input: z.object({ year: z.number(), month: z.number() })
   - month is 1-12 (not 0-indexed)
   - Calculate startDate = `${year}-${String(month).padStart(2, '0')}-01`
   - Calculate endDate using endOfMonth(new Date(year, month - 1)) and format as yyyy-MM-dd
   - Query sure table joining dosya + muvekkil, filter by son_tarih between startDate and endDate
   - Query durusma table joining dosya + muvekkil, filter by tarih between startDate and endDate
   - Return combined array as { events: MonthEvent[] }
   - Sort by tarih, then by type (süre first per D-04)

4. **Export:**
   ```typescript
   export const calendarRouter = createTRPCRouter({
     getMonthEvents: protectedProcedure.input(z.object({...})).query(async ({ input }) => {...})
   })
   ```
