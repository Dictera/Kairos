## Interaction Contracts

### Form Validation Display

- Required field errors appear below the field as `text-sm text-destructive` after submit attempt
- Inline validation fires on blur for email and phone fields (not on every keystroke)
- vergi_no: validates on blur — shows "VKN/TCKN 10 veya 11 hane olmalıdır" if invalid
- IBAN: validates on blur — shows "Geçersiz IBAN formatı (TRXXXXXXXXXXXXXXXXXXXXXXXX gerekli)" if invalid
- Phone: validates on blur — shows "Geçersiz telefon formatı (05XXXXXXXXX gerekli)" if invalid

### Cascading Dropdown Behavior

1. User selects sigorta şirketi in karsitaraflar-tab
2. `avukat_id` field immediately resets to null
3. Avukat Select becomes enabled; shows loading state while bySirket query fetches
4. If sigorta şirketi has no linked avukatlar: SelectContent shows only "Yok / Bilinmiyor" item
5. If sigorta şirketi changes again: repeat reset and refetch

### Expand/Collapse Sigorta Şirketi Row

1. ChevronDown icon button toggles expanded state per row
2. Only one row expanded at a time (accordion behavior — collapse previous on expand)
3. Avukat sublist loads lazily on first expand (enabled TanStack Query + listWithAvukatlar)
4. ChevronDown rotates 180deg when expanded (CSS transform transition 150ms)

### Delete Confirmation

- Sigorta şirketi delete: AlertDialog — "Bu sigorta şirketini silmek istediğinize emin misiniz? Bağlı avukatlar listeden kaldırılacaktır."
- Avukat delete: AlertDialog — "Bu avukatı silmek istediğinize emin misiniz? Dosyalarda bu avukata yapılan bağlantılar kaldırılacaktır."
- Both use: Cancel ("İptal") + Destructive action ("Evet, Sil")

### Toast Notifications

- Success: `toast.success('Kaydedildi.')` — matches existing ayarlar pattern
- Delete success: `toast.success('Silindi.')` — matches existing ayarlar pattern
- Error: `toast.error('Kaydedilemedi. Lütfen tekrar deneyin.')` — matches existing ayarlar pattern

## Accessibility Notes

- All icon-only buttons must have `aria-label` — pattern established in `ayarlar-crud-section.tsx` (`aria-label={\`${item.ad} düzenle\`}`, `aria-label={\`${item.ad} sil\`}`)
- Avukat expand button: `aria-label={\`${sirketi.ad} avukatları göster/gizle\`}` + `aria-expanded={isOpen}`
- Select disabled state (`disabled={!selectedSirketId}`) must not trap focus
- AlertDialog uses `AlertDialogDescription` for contextual delete warning — required for screen reader context
