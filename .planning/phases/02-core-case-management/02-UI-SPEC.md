## Spacing Scale

Declared values (multiples of 4 only — standard Tailwind 8-point scale):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, table cell inline padding |
| sm | 8px | Compact spacing inside table rows, filter chip gaps |
| md | 16px | Default element spacing, form field gaps, card padding |
| lg | 24px | Section padding, card internal vertical rhythm |
| xl | 32px | Page content gap, between list toolbar and table |
| 2xl | 48px | Major section breaks, page-level top padding |
| 3xl | 64px | Not used in Phase 2 (no full-page hero sections) |

Exceptions:
- Touch targets for icon-only action buttons (delete, edit in table rows): minimum 44px height via `h-11` or padding to reach 44px
- Tabs trigger height: 36px (`h-9`) to match shadcn Tabs default

## Typography

All sizes use Geist variable font via `--font-sans`. No additional font family is introduced.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 14px (text-sm) | 400 (regular) | 1.5 | Table cell text, form help text, placeholder copy |
| Label | 14px (text-sm) | 600 (semibold) | 1.4 | Form labels, table column headers (TableHead), filter labels |
| Heading | 20px (text-xl) | 600 (semibold) | 1.2 | Page title (e.g. "Müvekkiller", "Dosyalar", "Dosya Detayı") |
| Display | 28px (text-2xl) | 600 (semibold) | 1.2 | Not used in Phase 2 — reserved for dashboard stats (Phase 4) |

Rule: Only 2 weights are used — 400 (regular) and 600 (semibold). No 500/700 intermediate weights.

## Color

All values are Tailwind CSS variables as defined in app/globals.css (Phase 8 Navy + Turuncu palette).

| Role | CSS Variable | Approximate Hex | Usage |
|------|-------------|-----------------|-------|
| Dominant (60%) | `--background` | #F5F0E8 (warm beige) | Page background, main content area |
| Secondary (30%) | `--card` / `--sidebar` | card: warm white / sidebar: #032539 navy | Cards, table container, sidebar nav |
| Accent (10%) | `--primary` | #FA991C orange | See reserved-for list below |
| Accent alt | `--accent` | #1C768F steel blue | Active tab underline, focus ring on inputs, breadcrumb current page |
| Destructive | `--destructive` | red (~oklch 0.577 0.245 27) | Delete button, AlertDialog destructive action |

Accent (orange `--primary`) reserved for:
- Primary CTA buttons ("Yeni Müvekkil Ekle", "Yeni Dosya Oluştur", "Kaydet")
- Active sidebar navigation item highlight
- Pagination current page indicator
- Focus ring on primary form submit button
- NOT used on table row hover, filter controls, or tab triggers

Accent alt (steel blue `--accent`) reserved for:
- Active tab underline (TabsTrigger selected state)
- Keyboard focus ring on inputs (`ring` token = orange by default — keep as-is from globals.css, do not override)
- Breadcrumb current page text

Status badge color mapping:
- "Aktif" badge: green (`bg-green-100 text-green-800`) — semantic success, not part of palette
- "Arşivlenmiş" badge: gray (`bg-muted text-muted-foreground`)

Deadline urgency colors (Phase 4 will own these; defined here for empty-tab placeholders):
- < 3 days: `text-destructive` (red)
- < 7 days: `text-amber-600` (yellow-amber)

## Page and Interaction Inventory

### Müvekkil List (`/muvekkiller`)

Layout: Full-width table under page header.

Toolbar (always visible, not collapsible — D-04 pattern applied to müvekkil list):
- Search input (left): placeholder "İsim veya TC/Vergi No ile ara..."
- "Yeni Müvekkil Ekle" button (right, primary orange)

Table columns (Claude's discretion — CONTEXT.md §Claude's Discretion):
`Ad Soyad | Telefon | TC / Vergi No | Bağlı Dosya Sayısı | İşlemler`

- Bağlı dosya sayısı: numeric count; if 0 shows "—"
- İşlemler column: DropdownMenu with "Düzenle" and "Sil" actions
- Row click navigates to `/muvekkiller/[id]`

Pagination: shadcn Pagination, default page size 25 (D-02 range: 25-50; using lower bound for müvekkil list which will be smaller)

Loading state: Skeleton rows (5 rows) while data loads

### Müvekkil Detail (`/muvekkiller/[id]`)

Layout: Breadcrumb → Card with müvekkil info → linked dosyalar table

Card content: Ad Soyad, Telefon, E-posta, TC/Vergi No, Adres, Kayıt Tarihi
Action buttons (top-right of card): "Düzenle" (secondary) | "Sil" (destructive, triggers AlertDialog)

Linked dosyalar: compact table — Dosya No | Tür | Durum | Talep Tutarı — max 10 rows, no pagination, "Tüm Dosyaları Gör" link if more than 10

### Müvekkil Create/Edit (`/muvekkiller/yeni`, `/muvekkiller/[id]/duzenle`)

Layout: Single-page form, max-w-2xl centered in content area.

Fields:
- Ad Soyad (required, text)
- Telefon (optional, text)
- E-posta (optional, email)
- TC No / Vergi No (optional, text — single field, user enters one or the other)
- Adres (optional, textarea)

Form actions: "Kaydet" (primary, right) | "Vazgeç" (ghost, left — navigates back)

### Dosya List (`/dosyalar`)

Layout: Full-width table under page header.

Toolbar (always visible — D-04):
- Row 1: Search input (left, wider) + "Yeni Dosya Oluştur" button (right, primary orange)
- Row 2: Filter controls — Tür Select (STK / Asliye Ticaret / Asliye Hukuk / Tümü) + Durum Select (Aktif / Arşivlenmiş / Tümü) + Tarih range inputs (Başlangıç / Bitiş)

Table columns (D-03 — locked):
`Dosya No | Müvekkil Adı | Tür | Sigorta Türü | Karşı Sigorta Şirketi | Poliçe No | Durum`

- Tür column: Badge component (STK = blue variant, AT = gray, AH = gray)
- Durum column: Badge component (Aktif = green, Arşivlenmiş = gray)
- No plaka column (D-13: plaka only in detail page)
- Row click navigates to `/dosyalar/[id]`
- No inline action column — actions accessible from detail page

Pagination: shadcn Pagination, default page size 25 (lower bound of D-02 range)

Loading state: Skeleton rows (8 rows) while data loads

### Dosya Create/Edit (`/dosyalar/yeni`, `/dosyalar/[id]/duzenle`)

Layout: Single-page form, max-w-2xl centered. D-05: separate page, browser back works.

Fields (create):
- Avukat Dosya No (required, text — user-entered; uniqueness validation performed on save with inline error)
- Müvekkil (required, Select with search — lists all müvekkiller)
- Dosya Türü (required, Select: STK / Asliye Ticaret / Asliye Hukuk)
- Sigorta Türü (required, Select — from ayarlar list, seeded: Kasko / Trafik ZMSS / Sağlık / Hayat)
- Karşı Sigorta Şirketi (optional, Select — from ayarlar list)
- Talep Tutarı (optional, number input with "₺" prefix)
- Müvekkil Plaka No (optional, text — visible always, note: relevant for Kasko/Trafik)
- Açıklama (optional, textarea)

Form actions: "Kaydet" (primary) | "Vazgeç" (ghost)

Edit page: same form pre-populated. Add "Arşivle" action (separate from save, triggers AlertDialog confirmation).

### Dosya Detail (`/dosyalar/[id]`)

Layout: Breadcrumb → page header with Dosya No + Müvekkil Adı → 6-tab shell.

Header actions (top-right): "Düzenle" (secondary) | DropdownMenu with "Arşivle" and "Sil"

Tab order (D-14 — locked):
1. Genel Bilgiler — filled in Phase 2
2. Yargılama Süreci — placeholder (Phase 3)
3. Belgeler — placeholder (Phase 6)
4. Notlar / Zaman Çizelgesi — placeholder (Phase 6)
5. Karşı Taraflar — filled in Phase 2
6. Dosya Finansı — placeholder (Phase 6)

Filled tabs (Phase 2):

**Genel Bilgiler tab content:**
- All dosya fields displayed as labeled key-value pairs in a Card
- Fields: Dosya No, Müvekkil (link), Tür, Sigorta Türü, Karşı Sigorta Şirketi, Poliçe No, Talep Tutarı, Müvekkil Plaka No, Açıklama, Oluşturma Tarihi, Durum

**Karşı Taraflar tab content:**
- Card with fields: Karşı Sigorta Şirketi, Karşı Vekil Adı, Poliçe No, Karşı Taraf Plaka No
- Inline edit button on card — navigates to `/dosyalar/[id]/duzenle` with Karşı Taraflar section pre-scrolled (or a dedicated edit form section)
- All fields are optional — if all empty, show "Karşı taraf bilgisi henüz girilmedi." with Edit action

Empty tabs (D-16 — locked):
- Tab content: centered Lock icon (Lucide `Lock`, 24px, `text-muted-foreground`) + "Bu bölüm henüz yapılandırılmadı." text (body size, muted-foreground)
- No phase number or roadmap reference in placeholder text

### Ayarlar (`/ayarlar`)

Layout: Single page, three Card sections stacked vertically with Separator between.

Section 1: Sigorta Şirketleri (AYAR-01)
Section 2: Mahkemeler / Kurumlar (AYAR-02)
Section 3: Sigorta Türleri (D-09)
Section 4: Şifre Değiştirme Kılavuzu (AYAR-03) — static text, no backend

Each CRUD section pattern:
- Section header: "Sigorta Şirketleri" (heading size, semibold) + "Ekle" button (primary, right)
- List: simple table — Ad | İşlemler (Düzenle / Sil icon buttons)
- Add/Edit: inline expand row OR small Dialog (Dialog preferred for consistency)
- Delete: AlertDialog confirmation before removal

## Interaction Contracts

### Search Behavior
- Turkish-aware search: `lower_tr()` custom SQLite function (RESEARCH.md finding) — search must handle ş/Ş, ğ/Ğ, ü/Ü, ö/Ö, ç/Ç, ı/I, İ/i case-insensitively
- Debounce: 300ms after last keystroke before triggering tRPC query
- Search applies server-side, not client-side

### Form Validation
- Validation: react-hook-form + zod (already installed)
- Errors display inline below each field via `FormMessage`
- Form cannot be submitted while validation errors are present
- Required fields marked with "*" (asterisk) adjacent to label

### Table Row Actions
- Edit: navigates to edit page (not modal — D-05, D-06)
- Delete: triggers AlertDialog before any mutation
- Archive: triggers AlertDialog before mutation (dosya only)
- Row click (outside action column): navigates to detail page

### Pagination
- Page size: 25 rows (Dosya list), 25 rows (Müvekkil list) — from D-02
- shadcn Pagination component: First/Prev/numbered pages/Next/Last pattern
- Current page persists in URL query param (`?sayfa=2`)

### Tab Navigation
- shadcn Tabs — keyboard navigable (arrow keys between triggers)
- Active tab persists in URL hash (`#genel-bilgiler`, `#karsitaraflar`, etc.)
- Empty tab triggers are clickable but content shows placeholder only (D-16)

### Toast Notifications
- sonner (already installed): position `bottom-right`
- Duration: 4 seconds for success, 6 seconds for error
- No action button needed on toasts in Phase 2
