# Plan 02-04: Ayarlar Page — CRUD Sections + Şifre Kılavuzu

## Objective

Build the Ayarlar (settings) page with three CRUD sections — Sigorta Şirketleri, Mahkemeler / Kurumlar, and Sigorta Türleri — each with add, edit (Dialog), delete (AlertDialog) flows. A fourth static section provides the password-change guide (AYAR-03). Uses a single reusable `AyarlarCrudSection` component wired to different tRPC procedure sets. Satisfies AYAR-01, AYAR-02, AYAR-03.

Create `components/ayarlar/ayarlar-crud-section.tsx` as `'use client'`:

The component is generic over the entity type. Since TypeScript generics can be complex with tRPC, use a typed props interface:

```typescript
interface AyarlarItem {
  id: number
  ad: string
  sehir?: string | null  // mahkeme only
}

interface AyarlarCrudSectionProps {
  title: string
  items: AyarlarItem[] | undefined
  isLoading: boolean
  onAdd: (values: { ad: string; sehir?: string }) => Promise<void>
  onEdit: (id: number, values: { ad: string; sehir?: string }) => Promise<void>
  onDelete: (id: number) => Promise<void>
  showSehir?: boolean  // true for mahkeme section
}
```

State:
```typescript
const [dialogOpen, setDialogOpen] = useState(false)
const [editingItem, setEditingItem] = useState<AyarlarItem | null>(null)
const [deleteTarget, setDeleteTarget] = useState<AyarlarItem | null>(null)
const [formAd, setFormAd] = useState('')
const [formSehir, setFormSehir] = useState('')
```

Layout per section (wrapped in `<Card>`):
```
Card header:
  [ Title (text-base font-semibold) ]  [ Ekle button (primary, right) ]

Card content:
  Table: Ad | (Şehir — if showSehir) | İşlemler
  - İşlemler: Düzenle icon button (Pencil, 20px) | Sil icon button (Trash2, 20px)
  - Touch target: h-9 w-9 on icon buttons

  Empty state (if items.length === 0 and !isLoading):
    "Henüz kayıt eklenmedi."

  Loading state (if isLoading):
    3 skeleton rows
```

Dialog (for add/edit):
- Trigger: "Ekle" button or row "Düzenle" action
- Title: `editingItem ? 'Kaydı Düzenle' : title + ' Ekle'`
- Form inside Dialog:
  - "Ad" field: `<Input value={formAd} onChange={(e) => setFormAd(e.target.value)} placeholder="Ad giriniz..." />`
  - "Şehir" field (only when `showSehir === true`): `<Input value={formSehir} placeholder="Şehir (opsiyonel)" />`
  - Validation: `ad.trim().length > 0` required before submit; show inline error `<p className="text-sm text-destructive">Ad zorunludur.</p>` if submitted empty
- Actions: "İptal" (cancel) | "Kaydet" (primary)
- On "Kaydet":
  - If `editingItem`: call `onEdit(editingItem.id, { ad: formAd.trim(), sehir: formSehir.trim() || undefined })`
  - Else: call `onAdd({ ad: formAd.trim(), sehir: formSehir.trim() || undefined })`
  - On success: close dialog, clear form state, `toast.success('Kaydedildi.')`
  - On error: `toast.error('Kaydedilemedi. Lütfen tekrar deneyin.')`

AlertDialog (for delete):
- Trigger: row "Sil" action
- Title: "Kaydı Sil"
- Description: "Bu kaydı silmek istediğinize emin misiniz?"
- Actions: "İptal" | "Evet, Sil" (destructive)
- On "Evet, Sil": call `onDelete(deleteTarget.id)`, close AlertDialog, `toast.success('Silindi.')`

When "Düzenle" is clicked:
```typescript
setEditingItem(item)
setFormAd(item.ad)
setFormSehir(item.sehir ?? '')
setDialogOpen(true)
```

When "Ekle" is clicked:
```typescript
setEditingItem(null)
setFormAd('')
setFormSehir('')
setDialogOpen(true)
```

Create `components/ayarlar/ayarlar-page.tsx` as `'use client'`:

Wire three `AyarlarCrudSection` instances with their respective tRPC calls:

```typescript
'use client'

import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query'
import { useTRPC } from '@/lib/trpc/context'
import { toast } from 'sonner'
import { AyarlarCrudSection } from './ayarlar-crud-section'
import { Separator } from '@/components/ui/separator'
import { Card, CardContent, CardHeader, CardTitle } from '@/components/ui/card'

export function AyarlarPage() {
  const trpc = useTRPC()
  const qc = useQueryClient()

  // Sigorta Şirketleri
  const { data: sigortaList, isLoading: sigortaLoading } = useQuery(
    trpc.ayarlar.sigortaSirketi.list.queryOptions()
  )
  const addSigorta = useMutation(trpc.ayarlar.sigortaSirketi.create.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.sigortaSirketi.list.queryKey() }),
  }))
  const editSigorta = useMutation(trpc.ayarlar.sigortaSirketi.update.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.sigortaSirketi.list.queryKey() }),
  }))
  const delSigorta = useMutation(trpc.ayarlar.sigortaSirketi.delete.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.sigortaSirketi.list.queryKey() }),
  }))

  // Mahkemeler
  const { data: mahkemeList, isLoading: mahkemeLoading } = useQuery(
    trpc.ayarlar.mahkeme.list.queryOptions()
  )
  const addMahkeme = useMutation(trpc.ayarlar.mahkeme.create.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.mahkeme.list.queryKey() }),
  }))
  const editMahkeme = useMutation(trpc.ayarlar.mahkeme.update.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.mahkeme.list.queryKey() }),
  }))
  const delMahkeme = useMutation(trpc.ayarlar.mahkeme.delete.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.mahkeme.list.queryKey() }),
  }))

  // Sigorta Türleri
  const { data: sigortaTuruList, isLoading: sigortaTuruLoading } = useQuery(
    trpc.ayarlar.sigortaTuru.list.queryOptions()
  )
  const addSigortaTuru = useMutation(trpc.ayarlar.sigortaTuru.create.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.sigortaTuru.list.queryKey() }),
  }))
  const editSigortaTuru = useMutation(trpc.ayarlar.sigortaTuru.update.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.sigortaTuru.list.queryKey() }),
  }))
  const delSigortaTuru = useMutation(trpc.ayarlar.sigortaTuru.delete.mutationOptions({
    onSuccess: () => qc.invalidateQueries({ queryKey: trpc.ayarlar.sigortaTuru.list.queryKey() }),
  }))

  return (
    <div className="space-y-8">
      <AyarlarCrudSection
        title="Sigorta Şirketleri"
        items={sigortaList}
        isLoading={sigortaLoading}
        onAdd={(v) => addSigorta.mutateAsync(v)}
        onEdit={(id, v) => editSigorta.mutateAsync({ id, ...v })}
        onDelete={(id) => delSigorta.mutateAsync({ id })}
      />

      <Separator />

      <AyarlarCrudSection
        title="Mahkemeler / Kurumlar"
        items={mahkemeList}
        isLoading={mahkemeLoading}
        onAdd={(v) => addMahkeme.mutateAsync(v)}
        onEdit={(id, v) => editMahkeme.mutateAsync({ id, ...v })}
        onDelete={(id) => delMahkeme.mutateAsync({ id })}
        showSehir={true}
      />

      <Separator />

      <AyarlarCrudSection
        title="Sigorta Türleri"
        items={sigortaTuruList}
        isLoading={sigortaTuruLoading}
        onAdd={(v) => addSigortaTuru.mutateAsync(v)}
        onEdit={(id, v) => editSigortaTuru.mutateAsync({ id, ...v })}
        onDelete={(id) => delSigortaTuru.mutateAsync({ id })}
      />

      <Separator />

      {/* AYAR-03: Static password change guide — no backend */}
      <Card>
        <CardHeader>
          <CardTitle className="text-base font-semibold">Şifre Değiştirme</CardTitle>
        </CardHeader>
        <CardContent className="space-y-3 text-sm text-muted-foreground">
          <p>
            Uygulama şifresi <code className="bg-muted px-1 py-0.5 rounded text-xs font-mono">.env</code> dosyasında
            <code className="bg-muted px-1 py-0.5 rounded text-xs font-mono ml-1">APP_PASSWORD</code> değişkeni olarak saklanmaktadır.
          </p>
          <p>Şifreyi değiştirmek için:</p>
          <ol className="list-decimal list-inside space-y-1">
            <li>Proje klasöründeki <code className="bg-muted px-1 py-0.5 rounded text-xs font-mono">.env</code> dosyasını bir metin editörüyle açın.</li>
            <li><code className="bg-muted px-1 py-0.5 rounded text-xs font-mono">APP_PASSWORD=yeni_şifreniz</code> satırını güncelleyin.</li>
            <li>Dosyayı kaydedin.</li>
            <li>Terminalde <code className="bg-muted px-1 py-0.5 rounded text-xs font-mono">npm run dev</code> komutunu yeniden başlatın.</li>
            <li>Tarayıcıda çıkış yapıp yeni şifrenizle giriş yapın.</li>
          </ol>
          <p className="text-xs">
            Not: <code className="bg-muted px-1 py-0.5 rounded text-xs font-mono">.env</code> dosyası asla kaynak kod deposuna eklenmemelidir.
          </p>
        </CardContent>
      </Card>
    </div>
  )
}
```

## Threat Model

| Threat | Severity | Mitigation |
|--------|----------|------------|
| Unauthenticated CRUD on settings tables | High | All ayarlar router procedures use `protectedProcedure`; middleware blocks unauthenticated requests to /ayarlar |
| Deleting sigorta_sirketi/sigorta_turu referenced by dosya rows | Medium | SQLite FK enforced (foreign_keys ON). Delete will fail at DB level with FK constraint error; surface as `toast.error('Kaydedilemedi...')`. Future: add specific FK error detection and user-friendly message |
| Deleting seeded sigorta_turu values (Kasko etc.) | Low | No protection against deleting seed values in Phase 2 — user is trusted (single-user app). If needed in future, add is_system flag |
| Oversized 'ad' input injection | Low | Zod `z.string().max(200)` on all ad fields; rejected server-side before DB write |
| XSS via settings data rendered | Low | All data rendered via React JSX auto-escaping; no rich text fields in ayarlar |
</threat_model>
