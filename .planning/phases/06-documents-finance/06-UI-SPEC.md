## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `oklch(0.952 0.012 80)` — warm beige | Background, page surfaces |
| Secondary (30%) | `oklch(0.969 0.008 20)` — off-white | Cards, panels, list items |
| Accent (10%) | `oklch(0.746 0.174 57)` — orange turuncu | Primary CTAs, active states, upload button |
| Destructive | `oklch(0.577 0.245 27.325)` — red | Delete actions only |

**Accent reserved for:** Upload button (belge), "Yeni Belge" / "Yeni Finans" CTAs, file type badge active states. Never use accent for passive information display.

**Destructive reserved for:** Document delete action, any irreversible data removal.

## Copywriting Contract

| Element | Turkish Copy | Notes |
|---------|-------------|-------|
| Primary CTA (belge) | "Belge Yükle" | Triggers file picker or confirms drag |
| Primary CTA (finans) | "Kaydet" | Saves finance entry form |
| Empty state — Belgeler tab | "Bu dosyaya henüz belge eklenmedi" | Heading only; body: "Dosya sekmesindeki yükleme alanını kullanın" |
| Empty state — Dosya Finansı tab | "Bu dosya için henüz finans kaydı yok" | Heading only; body: "Yukarıdaki form ile gelen/giden/masraf ekleyin" |
| Empty state — Finans dashboard | "Henüz finans kaydı girilmedi" | Body: "Tüm dosyalardan gelen/giden/masraf kayıtları burada görünür" |
| Error — invalid file type | "İzin verilmeyen dosya türü. Yalnızca PDF, DOC, DOCX, JPG, PNG kabul edilir." | Inline error under upload zone |
| Error — file too large | "Dosya boyutu 20 MB'ı aşamaz." | Inline error under upload zone |
| Error — upload failed | "Yükleme başarısız. Lütfen tekrar deneyin." | Toast or inline |
| Destructive confirmation — belge sil | "Bu belgeyi silmek istediğinizden emin misiniz? Bu işlem geri alınamaz." | AlertDialog body |
| Destructive confirmation — finans sil | "Bu finans kaydını silmek istediğinizden emin misiniz?" | AlertDialog body |

**Destructive actions in this phase:**
1. Belge silme (document delete) — AlertDialog confirmation required before disk+DB delete
2. Finans kaydı silme — AlertDialog confirmation required before DB delete
