## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge padding |
| sm | 8px | Compact element spacing, form field gaps within group |
| md | 16px | Default element spacing, form field spacing (`space-y-4`), card padding |
| lg | 24px | Section padding, card header gaps |
| xl | 32px | Layout gaps, section breaks between tabs |
| 2xl | 48px | Major section breaks, empty state vertical padding |
| 3xl | 64px | Page-level spacing |

Exceptions:
- **Touch targets**: Minimum 44px × 44px for icon-only buttons per accessibility standards
- **Tab content**: `mt-4` (16px) below TabsList per existing pattern

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label | 14px | 600 (semibold) | 1.5 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 24px | 600 (semibold) | 1.2 |

**Notes:**
- Body and Label share 14px size but differ in weight — Label uses `text-sm font-semibold text-muted-foreground` per existing `Row` pattern in `genel-bilgiler-tab.tsx`
- Heading matches `text-lg font-semibold` (`text-lg` = 18px ≈ 20px with line-height 1.2)
- Display matches `text-xl font-semibold` per existing page headers (`muvekkil-detail.tsx`)
- Only 2 weights used: 400 (regular) and 600 (semibold) — consistent across codebase

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#F5F0E8` (warm beige / `--background`) | Page backgrounds, outer surfaces |
| Secondary (30%) | `#032539` (navy / `--sidebar`) + `#FFFFFF` (`--card`) | Sidebar navigation, card surfaces, popover backgrounds |
| Accent (10%) | `#FA991C` (orange / `--primary`) + `#1C768F` (steel blue / `--accent`) | See reserved-for list |
| Destructive | `oklch(0.577 0.245 27.325)` (red / `--destructive`) | Delete confirmations, error banners only |

Accent reserved for:
- **Orange (`--primary`)**: CTA buttons, focus rings, active tab indicators, primary actions, linked text, timeline event dots for creation/update events
- **Steel blue (`--accent`)**: Secondary buttons, info badges, STK process stage badges, timeline event dots for stage transitions, kusur oranı display bars

Destructive reserved for:
- Delete actions (with AlertDialog confirmation)
- Error state banners (red background at 10% opacity + red border at 30% opacity per existing pattern)
- Validation error messages (FormMessage default red)

## Interaction Patterns

### Notes CRUD (D-02, D-03)

**NotList component:**
- Top section: "Notlar" heading + "Not Ekle" Button (primary, sm)
- Note items rendered as `Card` with `CardContent`:
  - Note content (`whitespace-pre-wrap`)
  - Timestamp formatted `tr-TR` locale
  - Edit/Delete action icons (Pencil + Trash2 lucide icons, ghost variant, sm)
- Edit mode: inline Textarea replaces content display
- New note: expand inline form above list on "Not Ekle" click
- Delete: AlertDialog confirmation

### Activity Timeline (D-04)

**Timeline component:**
- Section heading: "Zaman Çizelgesi"
- Vertical timeline with left-aligned dots/lines (2px border-l)
- Each event: dot (8px circle, colored by event type) + text + timestamp
- Event type colors:
  - `olusturma` → primary (orange)
  - `surec_asama` → accent (steel blue)
  - `finans` → green-600
  - `belge` → muted-foreground
  - `not` → primary (orange, lighter)
  - `durusma` → blue-600
  - `sure` → amber-600
  - `guncelleme` / `durum_degisikligi` → muted-foreground
- Most recent events at top
- Maximum 50 events displayed with "Tümünü Gör" link if more exist
- Empty state: muted illustration + copy from Copywriting Contract

### Kusur Oranı (D-09, D-10, D-11)

**In form (edit mode):**
- Karşı Taraf Kusur Oranı: number input (0-100, integer only, step=1)
- Müvekkil Kusur Oranı: read-only display showing `100 - karsi` value
- Both fields side by side in 2-column grid

**In view mode (InfoRow pattern):**
- Only display values where kusur_orani_karsi > 0 (per D-10)
- Show as: "Karşı Taraf Kusur Oranı: 75%" + "Müvekkil Kusur Oranı: 25%"
- If kusur_orani_karsi is null → show "—" (not entered)

### Note Edit/Delete (D-03)

**Delete confirmation:** AlertDialog with "Bu notu silmek istediğinize emin misiniz? Bu işlem geri alınamaz."
**Edit:** Click edit icon → note content becomes Textarea with Save/Cancel buttons

### Field Grouping in Forms (D-19, D-23)

**Müvekkil form grouping:**
- Group 1: "Kimlik Bilgileri" — Ad, Soyad, TC/Vergi No
- Group 2: "İletişim" — Telefon, IBAN
- Group 3: "Adres" — Adres (full-width Textarea)
- Group 4: "Notlar" — Notlar (full-width Textarea)

**Dosya form grouping:**
- Group 1: "Temel Bilgiler" — Dosya No, Müvekkil, Tür
- Group 2: "Sigorta Bilgileri" — Sigorta Türü, Karşı Sigorta Şirketi, Müvekkil Sigorta/Kasko Şirketi, Talep Tutarı, Müvekkil Poliçe No, Hasar Dosya No
- Group 3: "Kaza Bilgileri" — Kaza Tarihi, Kusur Oranı (Karşı Taraf + auto-calculated Müvekkil), Müvekkil Plaka
- Group 4: "Açıklama" — Açıklama (full-width Textarea)

Each group separated by `Separator` component with group label as `h3 text-sm font-semibold`.

### Belge Category Expansion (D-16, D-17)

**New categories added to BELGE_KATEGORILER:**
- Dilekçe, Karar, Poliçe, Sigorta poliçesi, Hasar dosyası, Vekaletname _(existing)_
- İhtarname, Bilirkişi Raporu, Tutanak, Tebliği, Diğer _(new)_

**Category-based file naming (D-17):**
- When uploading, suggested filename = `{kategori adı}{orijinal uzantı}`
- E.g., file "scan.pdf" + category "İhtarname" → suggested "İhtarname.pdf"
- Duplicate handling: append counter — "İhtarname.pdf", "İhtarname-2.pdf"

### Stage Restructure Visualization (D-12, D-14)

**Stepper display:**
- STK stages (9): İhtar → Arabuluculuk → Başvuru → Ön İnceleme → Bilirkişi → Islah → Karar → İtiraz → Kesinleşme
- Mahkeme stages (12): Dava Dilekçesi Tebliğ → Cevap Dilekçesi Tebliğ → Replik Dilekçesi Tebliğ → Duplik Dilekçesi Tebliğ → Ön İnceleme → Bilirkişi → Duruşmalar → Karar → Karar Tebliğ → İstinaf → Temyiz → Kesinleşme
- Current stage highlighted with primary color (orange), past stages with accent (steel blue)
- Future stages muted
