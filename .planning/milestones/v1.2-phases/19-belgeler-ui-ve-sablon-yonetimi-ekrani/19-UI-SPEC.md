## Interaction Contracts

### Flow 1: "Şablondan Üret" (BUI-01 → BUI-05)

1. **User opens Belgeler tab** → `SablondanUret` component mounts above `BelgeUpload`
2. **User selects category filter** (STK/Mahkeme/Genel/Tümü) → Command list filters client-side
3. **User searches or selects template** from Command dropdown → `selectedTemplate` state set
4. **User clicks "Şablondan Üret"** → `pdfRouter.generate` mutation triggered
5. **Progress modal opens** immediately with step 1 active ("Şablon dolduruluyor…")
6. **Backend executes:** render → convert → archive (3 steps)
7. **On success:**
   - Modal closes automatically
   - `toast.success('PDF üretildi.')`
   - `queryClient.invalidateQueries(trpc.belge.list.queryKey({ dosya_id: dosyaId }))`
   - `BelgeList` refreshes; new PDF appears at top with accent border + template subtitle
8. **On error (missing variables):**
   - Modal closes
   - `toast.error(err.message)` — message already in Turkish from backend
   - Message format: "{field label} henüz girilmemiş — {tab adı} sekmesinden ekleyin."
   - No clickable tab links, no modal with tab-switch buttons (D-14)
9. **Modal state reset** on close to prevent stale step display on next generation

### Flow 2: Template Variable Catalog (BUI-06, BUI-07)

1. **User navigates to Ayarlar → Şablon Yönetimi**
2. **User clicks a template row** → `VariableCatalogModal` opens
3. **Modal shows:** template name in title, alphabetical variable list with badges
4. **Known variables** (matched against `VARIABLE_REGISTRY`): green "✓ Bilinen" badge
5. **Unknown variables:** amber outline "⚠ Bilinmeyen" badge
6. **User closes modal** → no side effects, pure read-only view

### Flow 3: Variable Cheat-Sheet (BUI-08, BUI-09)

1. **User navigates to Ayarlar** → sees "Değişken Listesi" summary card
2. **User clicks "Tüm değişkenleri gör"** → navigates to `/ayarlar/degiskenler`
3. **Full page renders** `VARIABLE_REGISTRY` grouped by tab, with filter documentation
4. **Page is static** — no data fetching, instant load

### Flow 4: Missing-Variable Pre-Check Error (BUI-03, D-14)

1. **User clicks "Şablondan Üret"** with missing required data
2. **Backend `pdfRouter.generate` throws `TRPCError` with `code: 'BAD_REQUEST'`**
3. **Client `onError` handler:**
   - Detects `BAD_REQUEST` code
   - Displays `toast.error(err.message)` directly
   - Message example: "STK esas numarası henüz girilmemiş — Süreç sekmesinden ekleyin."
4. **No additional UI** — no modal, no deep-link, no tab switcher (D-14)
