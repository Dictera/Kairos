    2. `convert_with_libreoffice(input_path: str, output_dir: str, libreoffice_path: str, timeout: int = 120) -> str`:
       - Decorated with `@retry(...)` from tenacity:
         ```python
         @retry(
             reraise=True,
             stop=stop_after_attempt(3),
             wait=wait_exponential(multiplier=1, min=4, max=10),
             retry=retry_if_exception_type((subprocess.TimeoutExpired, LibreOfficeError)),
         )
         ```
       - Create temp profile dir with `tempfile.mkdtemp(prefix=f"lo-{uuid.uuid4().hex}")`.
       - Build command as list (NO `shell=True`):
         ```python
         cmd = [
             libreoffice_path,
             f"-env:UserInstallation=file:///{lo_profile.replace('\\', '/')}",
             "--headless",
             "--convert-to", "pdf",
             "--outdir", output_dir,
             input_path,
         ]
         ```
       - Call `subprocess.run(cmd, capture_output=True, text=True, timeout=timeout)`.
       - If `returncode != 0`: raise `LibreOfficeError(f"LibreOffice convert failed: {result.stderr}")`.
       - Compute expected PDF path: `os.path.join(output_dir, os.path.splitext(os.path.basename(input_path))[0] + ".pdf")`.
       - If expected PDF does not exist: raise `LibreOfficeError("PDF output not created")`.
       - Return the expected PDF path.
       - In `finally` block: `shutil.rmtree(lo_profile, ignore_errors=True)`.

    3. All required imports: `os`, `shutil`, `subprocess`, `tempfile`, `uuid`, `tenacity.retry`, `tenacity.stop_after_attempt`, `tenacity.wait_exponential`, `tenacity.retry_if_exception_type`, `tenacity.reraise`.

    IMPORTANT: The `reraise=True` parameter must be passed to `@retry` so the original exception propagates after max attempts.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Node.js → Python sidecar | Untrusted file paths and contexts cross into subprocess execution |
| Python → LibreOffice | Subprocess call with file paths; must prevent injection |
| File system → PDF output | Temp files created and must be cleaned up to prevent info disclosure |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-01 | Tampering | handle_render template_path | mitigate | Path validation happens in tRPC router (Phase 17 Plan 03); sidecar assumes caller has validated |
| T-17-02 | Tampering | handle_convert input_path | mitigate | Same as T-17-01 — tRPC router validates paths resolve under uploads/templates/ |
| T-17-03 | Injection | subprocess.run in convert.py | mitigate | Arguments passed as list, never `shell=True`; no string interpolation of user data into command |
| T-17-04 | Denial of Service | LibreOffice hang | mitigate | `subprocess.run(timeout=120)` + tenacity max 3 attempts; per-invocation temp profiles prevent disk fill |
| T-17-05 | Information Disclosure | Temp profile directory | mitigate | `shutil.rmtree(lo_profile, ignore_errors=True)` in `finally` block guarantees cleanup |
| T-17-06 | Information Disclosure | Rendered DOCX temp file | accept | Temp file is passed back to Node.js and archived in Phase 18; Node.js `safeUnlink` handles cleanup on failure |
