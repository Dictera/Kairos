## UI Structure

### 1. Retirement Confirmation Modal (AlertDialog)

Triggered automatically on first app launch when old tables (`dilekce_sablonu`, `dilekce_odt_sablonu`) are detected and retirement flag is not set.

```tsx
<AlertDialog open={showRetirementModal} onOpenChange={setShowRetirementModal}>
  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>Eski Sistemleri Temizle</AlertDialogTitle>
      <AlertDialogDescription>
        Eski dilekçe ve ODT şablonları kalıcı olarak silinecek — onaylıyor musunuz?
      </AlertDialogDescription>
    </AlertDialogHeader>
    <AlertDialogFooter>
      <AlertDialogCancel>Vazgeç</AlertDialogCancel>
      <AlertDialogAction
        onClick={handleRetire}
        className="bg-destructive text-destructive-foreground hover:bg-destructive/90"
      >
        Onayla
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

**Key decisions (from D-03, D-05, D-06):**
- Modal is **simple and focused** — title + description + two buttons only
- No pipeline status, no extra information, no health check results (D-05, D-06)
- "Onayla" button uses **destructive** styling (red) to signal irreversible action
- "Vazgeç" is the default cancel action (AlertDialogCancel)
- Modal reappears on next launch if user cancels (D-03) — no permanent skip

### 2. Sidebar Navigation Update

In `components/app-sidebar.tsx`, replace the existing nav item:

```tsx
// BEFORE:
{ label: 'Dilekçeler', href: '/dilekce', icon: FileEdit }

// AFTER:
{ label: 'Şablon Yönetimi', href: '/ayarlar', icon: Settings }
```

**Key decisions (from D-07):**
- Navigation change ships with code update **before** retirement runs
- Icon changes from `FileEdit` to `Settings` (or `FileText` — see Agent's Discretion)
- Link points to `/ayarlar` (Ayarlar page where Şablon Yönetimi section lives)

### 3. Next.js Redirect Configuration

In `next.config.ts`, add redirect rules for old `/dilekce` routes:

```typescript
const nextConfig: NextConfig = {
  serverExternalPackages: ['better-sqlite3'],
  redirects: async () => [
    {
      source: '/dilekce',
      destination: '/ayarlar',
      permanent: false, // soft redirect
    },
    {
      source: '/dilekce/:path*',
      destination: '/ayarlar',
      permanent: false,
    },
  ],
}
```

**Key decisions (from D-08):**
- Redirects are **temporary** (`permanent: false`) — preserves flexibility
- Catches all sub-routes (`:path*`) including `/dilekce/yeni`, `/dilekce/odt-yukle`, `/dilekce/[id]`
- Redirect target is `/ayarlar` (soft landing with Şablon Yönetimi visible)

## Interaction Contracts

### Flow: Retirement Trigger & Confirmation (TEMIZ-08, D-01 → D-04)

1. **User opens app / refreshes dashboard** → client checks retirement flag (DB + localStorage cache)
2. **If old tables exist AND flag not set** → `showRetirementModal` set to `true`
3. **AlertDialog opens** with title, description, "Vazgeç" and "Onayla" buttons
4. **User clicks "Vazgeç"** → modal closes, flag NOT set, modal will reappear on next launch (D-03)
5. **User clicks "Onayla"** → tRPC retirement mutation triggered
6. **Server executes cleanup:**
   - Run Drizzle DROP TABLE migration (`dilekce_sablonu`, `dilekce_odt_sablonu`)
   - Delete `./uploads/odt-templates/` folder
   - Delete stale code files (routers, routes, services)
   - Uninstall npm dependencies
   - Run import scan + `next build` validation
7. **On success:**
   - Server sets retirement flag in DB
   - Client receives success response
   - `toast.success('Eski sistemler temizlendi. Sayfa yenileniyor…')`
   - `window.location.reload()` after brief delay (D-04)
8. **On error:**
   - `toast.error('Temizlik işlemi başarısız oldu: ' + err.message)`
   - Modal remains open or reopens on next launch

### Flow: Sidebar Navigation (TEMIZ-07, D-07)

1. **Code deployed** → `app-sidebar.tsx` already contains "Şablon Yönetimi" link
2. **Old "Dilekçeler" link is gone** → users see new nav item immediately
3. **User clicks "Şablon Yönetimi"** → navigates to `/ayarlar`
4. **Ayarlar page** shows Şablon Yönetimi section (built in Phase 19)

### Flow: Old Route Redirect (TEMIZ-02, D-08)

1. **User visits `/dilekce` or any sub-route** (bookmark, browser history)
2. **Next.js redirect rule** matches source pattern
3. **HTTP 307** to `/ayarlar`
4. **User lands on Ayarlar page** with Şablon Yönetimi visible
