<objective>
Build the core archive module that moves generated PDFs from temp storage to a predictable archive path and atomically inserts a `belge` record plus activity log. Includes compensating rollback on DB failure.

Purpose: Phase 18's central requirement is that every generated PDF is durably archived and tracked in the database as a single atomic operation. This module implements the compensating transaction pattern: disk write first, DB transaction second, disk cleanup on DB failure.
Output: `lib/docx/archive.ts` with path builders, slug helpers, and the compensating transaction; plus unit tests.
</objective>

function safeUnlink(filePath: string) {
  try {
    if (!path.resolve(filePath).startsWith(TEMPLATES_BASE_PATH)) {
      console.error(`Path traversal attempt: ${filePath}`)
      return
    }
    if (fs.existsSync(filePath)) fs.unlinkSync(filePath)
  } catch (e) {
    console.error(`Failed to delete file from disk: ${filePath}`, e)
  }
}

    4. `buildArchivePath(date: Date, kategoriSlug: string, muvekkilSlug: string, plakaSlug: string | null, seq: number)` — returns `{ dir, filePath, relativePath }` where:
       - `year = String(date.getFullYear())`
       - `month = String(date.getMonth() + 1).padStart(2, '0')`
       - `dir = path.join(ARCHIVE_BASE, year, month, kategoriSlug)`
       - `baseName = plakaSlug ? \`${muvekkilSlug}-${plakaSlug}\` : muvekkilSlug`
       - If `isReservedWindowsName(baseName)` is true, append `-belge` to baseName
       - `fileName = \`${baseName}-${seq}.pdf\``
       - `filePath = path.join(dir, fileName)`
       - `relativePath = path.relative(process.cwd(), filePath).replace(/\\\\/g, '/')`
       - Throws `TRPCError` with code `'BAD_REQUEST'` if `path.resolve(filePath)` does not start with `ARCHIVE_BASE` (path traversal guard)

    5. `generateSlugs(muvekkilAd: string | null, dosyaNo: string, plaka: string | null)` — async function that:
       - Calls `runSidecarCommand({ command: 'slug', params: { text: muvekkilAd || \`dosya-${dosyaNo}\` } })` to get müvekkil slug (per D-03 fallback)

    6. `archivePdfAndCreateBelge(tempPdfPath: string, dosyaId: number, dosyaNo: string, sablonId: number, sablonAdi: string, belgeTuru: string, muvekkilSlug: string, plakaSlug: string | null, kategoriSlug: string)` — async function implementing the compensating transaction:
       - Step A (outside DB tx): `const now = new Date(); const { dir, filePath, relativePath } = buildArchivePath(now, kategoriSlug, muvekkilSlug, plakaSlug, seq);` BUT seq is not yet known. Therefore:

         - Then call `buildArchivePath` with the computed seq
       - Step B (outside DB tx): `fs.mkdirSync(dir, { recursive: true })` then `fs.renameSync(tempPdfPath, filePath)` (atomic same-drive move per RESEARCH)
       - Step C (inside DB tx): wrap in `try { ... } catch (error) { safeUnlinkArchive(filePath); throw error; }`
         - Inside `try`, run `await db.transaction(async (tx) => { ... }, { behavior: 'immediate' })`
         - Inside the tx callback:

           const [insertedBelge] = await tx.insert(belge).values({

       - If `renameSync` throws `EXDEV` (cross-device), catch it and fall back to `fs.copyFileSync(tempPdfPath, filePath)` followed by `fs.unlinkSync(tempPdfPath)`. If copy fails, clean up any partial file.
