### Field Order (within driver section)

1. Sürücü Adı — name first for quick identification
2. Sürücü Soyadı — surname next to name
3. Plaka — vehicle identifier, grouped with identity
4. Telefon — contact, format hint below
5. Poliçe No — insurance reference, last

In view mode InfoRow grid, layout order: Sürücü Adı | Sürücü Soyadı | Plaka | Telefon | Poliçe No. Poliçe No occupies left column on its row (5 items in 2-col grid = 3 rows, last row has 1 item).

## Validation Specification

| Field | Validation | Error Message | Trigger |
|-------|-----------|---------------|---------|
| surucu_ad | `z.string().max(200).nullable().optional().or(z.literal(''))` | — (length only) | On submit |
| surucu_soyad | `z.string().max(200).nullable().optional().or(z.literal(''))` | — (length only) | On submit |
| surucu_plaka | `z.string().max(10).nullable().optional().or(z.literal(''))` | — (no format enforcement, per D-06) | On submit |
| surucu_telefon | `z.string().regex(/^05[0-9]{9}$/, 'Geçersiz telefon formatı (05XXXXXXXXX gerekli)').nullable().optional().or(z.literal(''))` | "Geçersiz telefon formatı (05XXXXXXXXX gerekli)" | On submit |
| surucu_police_no | `z.string().max(100).nullable().optional().or(z.literal(''))` | — (length only) | On submit |

**Empty string handling:** All fields use `.or(z.literal(''))` pattern — empty strings pass validation as empty/optional. In `onSubmit`, use `|| undefined` to convert empty strings to `undefined` before mutation.

**Phone field UX detail (D-05):** Below the Telefon Input, add `<p className="text-xs text-muted-foreground">Format: 05XXXXXXXXX</p>` as a static hint. Validation error displays via `<FormMessage />` below the hint when regex fails.

**Plate field UX detail (D-06):** Placeholder "34 ABC 123" provides visual guidance only. No `z.regex()` validation — user validates manually.
